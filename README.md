# API Test Automation Framework (Kotlin)

![Build Status](https://github.com/mikailo7/api-test-framework/actions/workflows/ci.yml/badge.svg)

## 📌 Overview
This project demonstrates a simple API test automation framework built in Kotlin.

## 🚀 Features
- REST API testing
- JSON parsing with Gson
- Automated test cases
- Logging system
- CI/CD with GitHub Actions

## 🛠 Tech Stack
- Kotlin
- Gradle
- OkHttp
- Gson
- JUnit / Kotlin Test

./gradlew test
